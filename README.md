🔗 **Live:** https://andreslinares-tech.github.io/propiedades-ecuador-plan/

## Contenido

- 01 · Arquitectura macro
- 02 · Los 4 canales de intención
- 03 · Pipeline 3 zonas
- 04 · Arquitectura de bots
- 05 · Workflows
- 06 · Cronograma
- 07 · Prompts Bot-Base (5 bots completos con CFs, Add Contact Info, Trigger Workflows, Bot Transfers)
- 📚 Knowledge Base — recordatorio

## Actualización

El archivo source vive en el repo principal del proyecto. Cuando se modifica, se ejecuta `publish.sh` que hace push automático a este repo y GitHub Pages se actualiza en ~30 seg.

## Stack

- HTML estático single-file
- Tailwind CDN
- Geist font (Google Fonts)
- SVG inline
- JS vanilla para TOC + clipboard copy
